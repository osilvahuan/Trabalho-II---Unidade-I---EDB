# Trabalho II - Unidade I - EDB
Um programa capaz de avaliar empiricamente o tempo de execução de algoritmos e, a partir dos dados obtidos, comparar o crescimento do tempo com funções assintóticas conhecidas.

Como Compilar e Rodar

1- Clone o repositório;
2- Compile o código;
3- Execute o programa
4- O programa imprimirá no terminal os resultados em formato CSV (separados por ponto e vírgula), prontos para serem copiados e colados no Google Sheets ou Excel para geração de gráficos.
